Unit 1b

Atomic Structure

Eight instruments. Build the atom from what you measure.

  1. Module 01 Nucleus & Isotopes Build atoms. Mix isotopes. Watch the average shift.
  2. Module 02 Coulomb & Ionization Two charges on a track. Feel the energy well.
  3. Module 03 Shell Model & Core Charge IE data hides a pattern. Find the jumps.
  4. Module 04 Atomic Size Line up atoms. Watch them shrink — or grow.
  5. Module 05 Light & Energy A wave, a slider. How does colour carry energy?
  6. Module 06 Photoelectron Spectroscopy The spectrometer shows what the shell model missed.
  7. Module 07 Electron Configurations Read the peaks. Fill the subshells. Derive the config.
  8. Module 08 Electron Spin Place the arrows. The magnet knows if you're wrong.
