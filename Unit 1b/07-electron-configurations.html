      Why 3d appears

      Scandium’s spectrum showed a new place for electrons — 3d. As we’ve seen so far, s holds two, p holds six, and now we see that d holds 10. Now we can see that the periodic table is actually organized in a way that shows this pattern. On the next page, we can see the entire periodic table, and each electron configuration.
