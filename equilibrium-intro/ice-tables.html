ICE Tables

One way we use K is to find concentrations we cannot measure directly. An ICE table keeps track of how each concentration changes on the way to equilibrium.

Each example has a worked solution, then a “Your turn” problem to try on your own. Examples A to F are from Hebden, Chemistry 12, pages 63 to 69. Nothing is saved.

Before We Begin

Learning intentions

  • We will learn when a problem needs an ICE table, and when it doesn't.
  • We will learn how to fill in an ICE table one row at a time, using the coefficients of the balanced equation.
  • We will use the E row to calculate Kc or Kp, or to find an unknown concentration or pressure.

What Is an ICE Table?

When a reaction runs, the concentrations change until the system reaches equilibrium. An ICE table is how we keep track of those changes.

I: Initial. The concentrations at the start, before the reaction shifts.
C: Change. How much each concentration goes up or down as the reaction shifts.
E: Equilibrium. The concentrations once the system has reached equilibrium.

Every column follows one rule: I + C = E.

Other names: Hebden labels the same rows START, +Δ and = EQUIL, so the rule reads START + Δ = EQUIL. Some textbooks add a row on top for the Reaction and call it a RICE table. They all work the same way.

Recall: K is products over reactants, each raised to its coefficient. When we use concentrations, we call it Kc. Hebden writes Keq; for these problems, that is the same thing as Kc.

Does This Problem Need an ICE Table?

The first question we ask is whether time passes in the problem.

If the problem only describes a system that is already at equilibrium, there is nothing to keep track of. We go straight to Kc.

If something is put in a container and then left to react, the concentrations change. Therefore, we need an ICE table.

When the Start Is Unknown

Sometimes the value we don't know is in the I row. We give it a letter, X, and carry it through the table.

Important: we will not need the quadratic formula for these problems. Whenever it looks like we do, we can take the square root of both sides instead.

In the simulation, click the “Next step” button to see how X moves through the table. Then try one on your own.

Which Way Will It Shift?

Not every problem asks for a number. Sometimes it asks for a decision.

We calculate Q, the reaction quotient, using the starting concentrations. It is the same expression as Kc, at any moment.

If Q = Kc, the system is at equilibrium.
If Q is LESS than Kc, the reaction must shift to produce more PRODUCTS.
If Q is GREATER than Kc, the reaction must shift to produce more REACTANTS.

In the simulation, click the “Next step” button to compare Q with Kc. Then try three on your own.

Letting x Be the Change

When we don't know any value in the C or E rows, we let the variable be the change in concentration of one substance.

The coefficients tell us how the other changes compare. The side that started at zero must gain, so the other side must lose.

In the simulation, click the “Next step” button to see how x fills the table, and then how the square root solves it. Then try one on your own.

Disturbing an Equilibrium

When something is added to a system that is already at equilibrium, we use Le Châtelier's principle, but now with numbers.

First, we need Kc, from the equilibrium before anything was added.

Then the addition goes on the I row. The system will not shift by itself; something has to cause the shift.

In the simulation, click the “Next step” button to find Kc, then add the SO2 and watch the bulb shift. Then try one on your own.

Kp: ICE Tables With Pressures

When every substance is a gas, we can also write K using partial pressures. This is Kp.

Kc: uses concentrations, in mol/L.
Kp: uses partial pressures, in atm.

In a sealed flask at a constant temperature, the pressure of each gas goes up and down with its moles. Therefore, the ICE table works the same way: the C row still follows the coefficients. We fill it in with pressures instead of concentrations.

Total pressure: the sum of all the partial pressures. Sometimes it is the only equilibrium value we are given.

What to Take With You

Does time pass? If not, go straight to K. If it does, set up an ICE table.

Units: every value in the table is in mol/L for Kc, or atm for Kp. Convert moles first.

Fill in what we know first, then use I + C = E.

The C row follows the coefficients. One side is positive, and the other side is negative.

Additions and removals go on the I row.

No quadratic formula: take the square root of both sides.

A decision, not a number? Compare Q with K.
